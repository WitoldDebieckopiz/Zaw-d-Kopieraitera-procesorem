# Zaw-d-Kopieraitera-procesorem
Smutnym panom wszystko przeszkadza co jest podrobione i nie orginalne nawet jak jest to lepszej jakości podrabiania porcesorami Xeon z wysokiej półki procesorów też im to przeszkadza. 
Za podrabianie procesorem wpisują dauna i zespuł aspergera i Autyzm i schizofrenie.
